# Introduction
The idea behind this was discussed in [The Unhandled Exception Podcast](https://unhandledexceptionpodcast.com/posts/0013-devopswithdushyant/). The main objective of this website is to help others learn coding solutions as well as get some practice for us (solvers) at solving them.

## Hosting and architecture
This website is generated with DocFX and hosted on GitHub Pages. It is built and deployed automatically via GitHub Actions on every push to `main`.
